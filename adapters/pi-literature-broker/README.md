# pi-literature-broker

A Pi extension that registers the literature broker's tools: `literature_search`, `paper_resolve`, `paper_get` and
`citation_expand`. The broker itself lives in [`literature/broker/`](../../literature/broker/); this package only
registers its tools with Pi.

Documentation: [docs/research-literature.md](../../docs/research-literature.md),
[docs/literature/broker.md](../../docs/literature/broker.md) and
[docs/literature/broker-cancellation.md](../../docs/literature/broker-cancellation.md).
